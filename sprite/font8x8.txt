// Source of sprite/font8x8.png; regenerate with `go generate ./sprite`.
// Format: blank lines and lines starting with "//" are ignored. Each glyph is a
// header line holding its character code in hex (0xNN; the rest of the line is a
// free comment, conventionally the character itself) followed by exactly 8 rows of
// exactly 8 cells, top to bottom: '#' is ink, '.' is transparent. Every code from
// 0x20 to 0xFF appears exactly once: ASCII, then 0x7F (blank), then the cells 0x80..0x9F
// holding the characters Windows-1252 puts there (the euro sign, typographic quotes,
// dashes; sprite.Font draws their Unicode code points with these cells), then Latin-1.
//
// Metrics: capitals and digits are 5x7 in columns 1..5, rows 0..6 (baseline row 6);
// lowercase x-height is rows 2..6. Column 7 is blank; row 7 is used only by descenders
// (g j p q y , ; and their accented and symbol kin) and cedillas. An accented capital is
// its capital with one row left out, in rows 1..6 under a one-row accent, so it stays on
// the baseline and taller than a lowercase letter; an accented lowercase letter is its
// letter under a two-row accent.
